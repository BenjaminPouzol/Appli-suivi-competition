À propos du projet

Cette plateforme est avant tout un support d'apprentissage : elle est construite étape par étape, pour couvrir l'ensemble de la chaîne du développement web.

Les briques techniques

Frontend
Angular — la partie visible, exécutée dans le navigateur
Backend
Node.js, Express et TypeScript — le serveur qui répond aux demandes
Base de données
PostgreSQL, piloté par Prisma — le stockage durable des informations
Authentification
JWT — pour reconnaître un utilisateur d'une page à l'autre
Données externes
APIs Riot Games et football-data.org — les résultats réels

Où en est le projet

Les compétitions et les matchs sont enregistrés dans une base de données PostgreSQL, servis par l'API du backend, et peuvent désormais être créés, modifiés et supprimés depuis l'application.

Prochaine étape : l'authentification. Tant qu'elle n'est pas en place, n'importe quel visiteur peut modifier les données — c'est une faille connue, que l'étape 8 comblera.

Le détail de chaque étape, les concepts abordés et les choix techniques sont consignés dans le document d'apprentissage, à la racine du dépôt.
